# General Working Taste
- Writes long, highly structured briefs: explicit role assignment, numbered sections, and enumerated lists of required artifacts and features. Treat every enumerated item as a deliverable checklist, not a suggestion. Confidence: 0.9
- Frequently states anti-goals ("this is NOT a dashboard-only project", "production-grade") to fence off shallow interpretations — honor the negation strictly. Confidence: 0.9
- Wants the full vertical slice, not the visible output layer: ingestion → warehouse modeling → transformation → modeling → BI/presentation. Rejects "front-end only" deliverables. Confidence: 0.9
- Prefers breadth plus depth in a single build: a large number of components (many facts, many dashboards, many models) shipped together rather than a thin vertical slice done perfectly. Confidence: 0.8
- Wants everything asked for in one pass, including the "portfolio wrap" artifacts (README, presentation, case study, business impact report) — not just the code. Confidence: 0.85
- Prefers real, named, authoritative public data sources (Eurostat, OECD, WHO, OSM, national open-data portals) over synthetic/mocked data, and expects the pipeline to hit them live. Confidence: 0.85
- Asks for realistic-but-fictional target artifacts only when a live source genuinely doesn't cover the need, and wants that tradeoff called out. Confidence: 0.7
- Work is aimed at a hiring market: "strong enough to impress Senior X, Analytics Engineers, BI Managers, and Recruiters". Optimize for demonstrable breadth of skill, not narrow depth. Confidence: 0.85
- Prefers enterprise consulting visual style (McKinsey / Deloitte / PwC / KPMG / BCG): minimalist, modern, executive-friendly, professional palette, responsive, dark mode *and* light mode, accessibility compliant. Confidence: 0.85
- Wants executive-facing summary metrics and KPIs defined explicitly, not left to the consumer to derive. Confidence: 0.8
- Treats diagrams and written docs as first-class deliverables: architecture, data flow, ETL, lineage, ERD, plus data dictionary and ETL documentation. Diagrams are expected, not optional. Confidence: 0.85
- Values "compare performance" and "generate feature importance" — prefers multiple candidate approaches benchmarked against each other with evidence, over a single unexplained choice. Confidence: 0.8
